# TrafficControl

Многоагентный симулятор управления светофорами на четырёх связанных перекрёстках. Десять агентов обмениваются сообщениями через RabbitMQ. Система моделирует движение и очереди, а веб-интерфейс показывает светофоры, автомобили и журнал событий.

**Python · asyncio · RabbitMQ · FastAPI · Canvas API · Docker Compose**

## Сценарии

- Адаптация длительности фаз по данным датчиков.
- Координация зелёной волны.
- Разгрузка затора.
- Переход на резервный план при отказе датчика.
- Приоритетный проезд скорой помощи.

В проекте автоматизирована проверка всех пяти сценариев. Сейчас здесь опубликовано описание проекта.
